# AVG ACARS 0.1.2 — Seguridad 1.2 (portátil)
Paquetes completos para Microsoft Flight Simulator 2020 y X-Plane 11/12, preparados a partir de los instaladores oficiales 0.1.2 y los módulos de seguridad del 6 de noviembre de 2026.

- Cierre y desconexión al salir.
- Detección conservadora y evidencia de posibles accidentes para revisión AVG-001 (sin cargos automáticos).
- Cola persistente de incidentes.
- Conservación del login, PIREP y funcionamiento de vuelo existente.

**Instalación:** Descargar el ZIP correspondiente, extraerlo por completo y ejecutar el EXE dentro de la carpeta. No es un nuevo instalador. La versión 0.1.2 anterior sigue disponible como respaldo.

**Limitación:** Las pruebas automáticas no sustituyen las pruebas en Windows con el simulador. Un ACARS abierto y conectado a una misión puede seguir registrando el vuelo aunque sea una práctica personal. Para entrenamiento, desconectarlo.
